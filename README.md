## 三、核心算法模型

### 3.1 长度-体重幂律关系（Length-Weight Relationship, LWR）

鱼类体长与体重遵循经典的异速生长方程：

```
W = a × L^b
```

其中：
- `W`：体重（kg）
- `L`：体长（cm）
- `a`：条件因子（condition factor），种特定常数
- `b`：异速生长指数（allometric coefficient）

#### b 值含义

| b 值 | 生长类型 | 含义 |
|---|---|---|
| b = 3.0 | 等速生长 (Isometric) | 鱼体型随长度等比例放大，体型不变 |
| b < 3.0 | 负异速生长 (Negative Allometric) | 鱼越长越"瘦" |
| b > 3.0 | 正异速生长 (Positive Allometric) | 鱼越长越"胖" |

现实鱼类 b 值通常在 **2.5 ~ 3.5** 之间。

#### a 值计算

当已知某物种的 (L_min, W_min) 和 (L_max, W_max) 两条边界约束后，可通过以下方式确定 a：

```
已知 b 值，则 a = W_min / (L_min^b) = W_max / (L_max^b)
```

实际实现中，a 作为种特定参数存储在配置中（可在 CSV 中隐式存储或通过 Min/Max 反推）。

#### 游戏中实际生成算法

```python
def generate_fish_size(fish_species):
    # Step 1: 从概率分布中采样长度
    L = sample_length(fish_species)  # 见 3.3 节
    
    # Step 2: 通过幂律关系计算体重
    W = fish_species.a * (L ** fish_species.b)
    
    # Step 3: 检查是否为突变个体
    if is_mutated(fish_species):
        L, W = apply_mutation_bonus(L, W, fish_species)
    
    return L, W
```

### 3.2 长度分布概率密度函数

每条鱼种内，个体长度服从**截断正态分布**（Truncated Normal Distribution），约束在 [MinLength, MaxLength] 之间。

#### 概率密度函数

```
PDF(x) = φ((x - μ) / σ) / (σ × (Φ((b - μ)/σ) - Φ((a - μ)/σ)))
```

其中：
- `φ(z)` = 标准正态分布 PDF：`(1/√(2π)) × e^(-z²/2)`
- `Φ(z)` = 标准正态分布 CDF（累积分布函数）
- `a` = MinLength（下界）
- `b` = MaxLength（上界）
- `μ` = 均值，设为 `(a + b) / 2` 或略偏左（模拟小鱼多、大鱼少的自然种群结构）
- `σ` = 标准差，设为 `(b - a) / 6`（使 99.7% 个体落在 [a, b] 内）

#### 增强模型：Gamma 分布（推荐）

由于自然鱼类种群中**小鱼远多于大鱼**，更推荐使用 **Gamma 分布** 映射到 [MinLength, MaxLength] 区间：

```python
def sample_length(species):
    # Gamma 分布：shape=k, scale=θ
    # k 越大越接近正态，k 越小越右偏（小鱼多）
    k = 3.0 + species.rarity * 0.5  # 稀有鱼更均匀，常见鱼更偏
    theta = (species.max_length - species.min_length) / (k * 6)
    
    # 从 Gamma 采样并映射到区间
    raw = np.random.gamma(k, theta)
    L = species.min_length + raw
    L = np.clip(L, species.min_length, species.max_length)
    
    return L
```

**优势**：
- 自然模拟了 "小个体多、大个体少" 的种群结构
- 不会像均匀分布那样出现离谱的"正方形鱼"
- 参数可根据 Rarity 调节：高稀有度鱼种体型分布更均匀（因为本身就少见，个体差异小）

### 3.3 个体属性对售价/经验的加成模型

钓获鱼的实际售价和经验由 **基础值 × 多因子加成** 决定：

#### 售价公式

```
实际售价 = BasePrice_Gold × (1 + SizeBonus + MutationBonus + QualityBonus)
```

| 加成因子 | 公式 | 说明 |
|---|---|---|
| `SizeBonus` | `0.5 × (L - μ) / σ` | 体长偏离均值的标准差倍数，范围约 [-1.0, +1.0] |
| `MutationBonus` | `0.3 × MutationLevel` | 突变等级加成（见 3.4），范围 [0, +0.9] |
| `QualityBonus` | `0.0 ~ 0.2` | 随机品质波动（均匀分布），模拟"品相" |

最终加成控制在 `×0.5 ~ ×2.5` 之间，即 **半价到 2.5 倍价**。

#### 经验公式

```
实际经验 = ExpReward × (1 + SizeBonus × 0.8 + RarityBonus + MutationBonus × 0.5)
```

| 加成因子 | 公式 | 说明 |
|---|---|---|
| `RarityBonus` | `0.15 × Rarity` | 稀有度加成，稀有鱼经验更高 |
| 其他同售价 | — | SizeBonus 和 MutationBonus 同样生效 |

### 3.4 突变模型

#### 突变触发

```python
def is_mutated(species):
    rate = species.base_mutation_rate
    # 可使用鱼竿、饵料、技能等对 rate 进行加成
    return random.random() < rate
```

#### 突变等级

突变个体分为三个等级：

| 等级 | 概率（在突变前提下） | 体型突破 | 额外加成 |
|---|---|---|---|
| 普通突变 Lv.1 | 70% | 长度/体重可超出 MaxLength/MaxWeight 的 15% | 售价+30%，经验+20% |
| 稀有突变 Lv.2 | 25% | 长度/体重可超出 30% | 售价+60%，经验+40%，特殊外观 |
| 传说突变 Lv.3 | 5% | 长度/体重可超出 50% | 售价+100%，经验+70%，专属称号 |

#### 突变个体生成

```python
def apply_mutation_bonus(L, W, species, mutation_level):
    bonus_ratio = [0.15, 0.30, 0.50][mutation_level - 1]
    new_max_L = species.max_length * (1 + bonus_ratio)
    new_max_W = species.max_weight * (1 + bonus_ratio)
    
    # 重新采样，可能在超限范围内
    L_mutated = min(L * random.uniform(1.0, 1.0 + bonus_ratio), new_max_L)
    W_mutated = species.a * (L_mutated ** species.b)
    
    return L_mutated, W_mutated, mutation_level
```

### 3.5 补充拟合角度

#### 3.5.1 咬钩概率模型

```
咬钩概率 = 基础咬钩率 × 饵料吸引力 × 时间修正 × 天气修正 × 水层匹配度
```

- **基础咬钩率**：鱼种固有属性（0.01 ~ 0.30，稀有鱼更低）
- **饵料吸引力**：`Attractiveness / 100`
- **时间修正**：活跃时段匹配 ×1.2，不匹配 ×0.6
- **天气修正**：晴天 ×1.0，阴天 ×1.1，雨天 ×1.3，暴风雨 ×0.5
- **水层匹配度**：饵料水层与鱼水层匹配 ×1.0，相邻水层 ×0.7，跨层 ×0.3

#### 3.5.2 上钩后逃脱概率

```
逃脱概率 = 基础逃脱率 × (1 + FightPower/10) × (1 - 鱼竿强度/100)
```

- 挣扎强度越高，越容易脱钩
- 好鱼竿降低逃脱率

#### 3.5.3 鱼类刷新权重（Spawn Weight）

```
刷新权重 = 基础刷新率 × 稀有度修正 × 季节修正 × 天气修正 × 时间修正
稀有度修正 = 1.0 / (0.5 + 0.5 × Rarity)
```

- Rarity=1 的鱼权重为 1.0，Rarity=10 的鱼权重为 0.182
- 确保常见鱼经常出现，稀有鱼真正稀有

#### 3.5.4 成长模型（如游戏包含养鱼系统）

```
日增重 = 基础代谢率 × 饵料营养值 × 水温修正 × (1 - 当前体重/最大体重)
```

Logistic 生长曲线确保不会无限增长。

### 6.3 Spawn Weight 概率模型

某地图中钓获某鱼种的概率由 **Spawn Weight 归一化** 决定：

```
P(鱼A) = SpawnWeight_A / ΣSpawnWeight_i
        (i = 该地图所有可钓获鱼种)
```

#### SpawnWeight 计算

```
SpawnWeight = BaseWeight × RarityPenalty × HabitatMatch × AbundanceFactor
```

| 因子 | 公式 | 说明 |
|---|---|---|
| `BaseWeight` | `10000` | 基准权重常数 |
| `RarityPenalty` | `1.0 / (0.5 + 0.5 × Rarity)` | 稀有度惩罚：Rarity=1 → 1.0，Rarity=10 → 0.182 |
| `HabitatMatch` | `0.3 ~ 1.0` | 生态匹配度（见6.5节匹配表）。完美匹配1.0，勉强兼容0.3 |
| `AbundanceFactor` | `0.3 ~ 2.0` | 现实丰度系数。超常见鱼2.0，稀见鱼0.3 |

**最终 SpawnWeight 范围**：约 `100`（极稀有鱼）到 `25000`（超常见鱼）。

#### 设计哲学

- **Rarity低（常见鱼）** → 出现在更多地图 + 高SpawnWeight → 经常钓到
- **Rarity高（稀有鱼）** → 仅出现在特定地图 + 低SpawnWeight → 需要运气和技术
- **生态合理性**：淡水鱼不出现在海洋地图（洄游鱼和广盐性鱼除外）

### 6.1 表字段定义

`MapTable.csv` 是一个**关联表**，每行代表"某地图中可钓获的某鱼种及其出现权重"。同一地图的多行通过 `MapId` 关联。

| 属性名 | 数据类型 | 说明 |
|---|---|---|
| `MapFishId` | `int` | 唯一主键，自增 |
| `MapId` | `int` | 地图ID（同一地图共享相同MapId） |
| `MapName` | `string` | 地图中文名称（如"乡村池塘"） |
| `MapType` | `string` | 地图类型：池塘/湖泊/溪流/河流/河口/近海/珊瑚礁/远洋/深海/极地/红树林/运河 |

| `MaxDepth_m` | `float` | 该鱼在此地图出现的最大水深（可选） |

### 6.2 Spawn Weight 概率模型

某地图中钓获某鱼种的概率由 **Spawn Weight 归一化** 决定：

```
P(鱼A) = SpawnWeight_A / ΣSpawnWeight_i
        (i = 该地图所有可钓获鱼种)
```

#### SpawnWeight 计算

```
SpawnWeight = BaseWeight × RarityPenalty × HabitatMatch × AbundanceFactor
```

| 因子 | 公式 | 说明 |
|---|---|---|
| `BaseWeight` | `10000` | 基准权重常数 |
| `RarityPenalty` | `1.0 / (0.5 + 0.5 × Rarity)` | 稀有度惩罚：Rarity=1 → 1.0，Rarity=10 → 0.182 |
| `HabitatMatch` | `0.3 ~ 1.0` | 鱼种与该地图水域类型的生态匹配度。完美匹配1.0，勉强兼容0.3，不匹配则不出现在该地图 |
| `AbundanceFactor` | `0.5 ~ 2.0` | 该鱼在此类水域中的现实丰度系数。超常见鱼2.0，稀见鱼0.5 |

**最终 SpawnWeight 范围**：约 `150`（极稀有鱼在不匹配水域）到 `20000`（超常见鱼在完美水域）。

#### 设计哲学

- **Rarity低（常见鱼）** → 出现在更多地图 + 高SpawnWeight → 经常钓到
- **Rarity高（稀有鱼）** → 仅出现在特定地图 + 低SpawnWeight → 需要运气和技术
- **生态合理性**：淡水鱼不出现在海洋地图（洄游鱼和广盐性鱼除外）
