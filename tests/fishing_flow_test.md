## I-001: 完整钓鱼流程（正常路径）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 页面加载 | 标题画面"🎣 钓趣"出现，有"开始游戏"按钮 |
| 2 | 点击"开始游戏" | 切换到地图选择画面，至少看到"乡村池塘"可点击 |
| 3 | 点击"乡村池塘" | 进入钓鱼场景，蓄力条居中偏下显示，绿色目标区可见 |
| 4 | 按空格 | 光标从 0 开始向右运动 |
| 5 | 光标到达绿色区域时按空格 | 显示判定结果（Perfect!/Good!/Poor!） |
| 6 | 等待 1.5s | 自动进入等待阶段，浮漂出现，下方有循环进度条 |
| 7 | 等待鱼咬钩 | 浮漂从 idle → bobbing → sinking，显示 "Bite!" |
| 8 | 自动进入刺鱼阶段 HOOKING | 浮漂水波纹变红，显示抖动 "Hit!"，进度条开始减少 |
| 9 | 按空格 | 进入搏鱼阶段 CATCHING |
| 10 | 看到键从右向左移动，按空格打键 | 判定显示 Perfect!/Great!/Good!/Miss，耐力条变化 |
| 11 | 鱼耐力归零 | 显示 "Caught!"，500ms 后跳转到结算画面 |
| 12 | 结算画面 | 显示鱼名、品质颜色、体长体重、售价滚动动画、EXP |
| 13 | 点击"继续钓鱼"或"返回地图" | 回到钓鱼场景或地图选择 |

## I-005: 饵料消耗与切换

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 进入钓鱼场景 | 蓄力条下方显示 "饵料: 红蚯蚓 x10 (ATTR:40)" |
| 2 | 按 `B` 键 | 无变化（只有一种饵料时循环无效果）|
| 3 | 按 `2` 键 | 状态文本闪现 "Bait #2 not available" |
| 4 | Console: 加 3 种新饵料后按 `5` | 饵料切换为 "蚂蚱 x3 (ATTR:45)" |
| 5 | 按空格开始抛竿 | Console 输出 "[Bait] 消耗 1 蚂蚱，剩余=2" |
| 6 | 用 Console 只留 1 个红虫并装备 | 抛竿一次后，饵料耗尽自动卸下，显示 "无饵料" |
| 7 | 再次按空格抛竿 | Console 输出 "无饵料，使用基础吸引力"，仍可正常钓鱼 |

**Console 注入**:
```javascript
window._baitSystem.addBait(5, 3);  // 蚂蚱 x3
window._baitSystem.addBait(11, 2); // 亮片 x2
window._baitSystem.addBait(3, 1);  // 红虫 x1
// 清空红蚯蚓测试自动卸下
window._baitSystem.addBait(1, -10);
```
