# 🎣 钓趣（Fishing Fun）—— 项目章程

## 项目名称与愿景

**钓趣（Fishing Fun）** 是一款 2D 像素风横版钓鱼游戏。玩家将扮演一位垂钓爱好者，在风格迥异的水域间穿行，用手中的钓竿、渔轮、鱼线和鱼钩与水下世界博弈。项目愿景是用简洁、上瘾的玩法还原钓鱼的核心乐趣——抛竿时的期待、咬钩时的紧张、收线时的成就感——同时通过丰富的鱼类图鉴、装备系统和养成曲线，为玩家提供一个可以沉浸数十小时的轻松垂钓世界。

## 核心目标

- **打造三层递进的核心钓鱼循环**：抛竿（精度小游戏）→ 等待（节奏与悬念）→ 刺鱼/收线（节奏音游式判定），让每一次出竿都独一无二。
- **构建 300+ 鱼种的完整图鉴系统**：每种鱼有独立的行为参数、稀有度、出现条件和视觉表现，鼓励探索与收集。
- **设计有深度的装备养成体系**：钓竿、渔轮、鱼线、鱼钩四类装备各有 3–5 条属性，影响抛竿、等待时间和收线判定，让装备选择具有策略意义。
- **实现渐进式经济与成长曲线**：经验值（XP）采用指数曲线，等级解锁新地图、新装备和高级鱼种；金币（Gold）作为流通货币，维持良性循环。
- **提供多样化的地图与鱼饵生态**：15 张地图、35 种鱼饵、不同天气/时段条件，形成「地图 × 鱼饵 × 装备 × 时机」的四维策略空间。
- **确保单人体验完整闭环**：以单机离线可玩为首要目标，无需联网即可畅玩全部核心内容。
- **预留多人/扩展接口**：在代码层面保留账户系统、排行榜、烹饪系统、合成系统的接口位，为后续更新铺路。

## 超出 v1 范围（明确不做）

- 多人联机实时钓鱼、比赛或社交互动
- 玩家账户登录、云端存档、跨设备同步
- 烹饪系统、鱼料理制作与食材组合
- 装备合成、锻造或随机词条系统
- 内购、广告变现或任何商业化功能
- 3D 渲染、物理引擎或非像素画风
- 移动端原生打包（iOS/Android），但不排除通过 PWA 兼容
- 叙事/剧情系统、NPC 对话树或任务链
- 鱼塘经营、养殖或自动化挂机玩法

## 设计理念

- **玩法优先，美术为玩法服务**：像素风格不仅为了怀旧，更是为了让动画帧数可控、判定清晰、性能开销低，确保核心玩法的响应感。
- **深度来自组合，而非堆叠**：装备、鱼饵、地图、时段的组合应当产生有意义的策略选择，而不是用数值碾压让玩家机械升级。
- **节奏感即沉浸感**：钓鱼的三大阶段各自有独特的交互节奏——抛竿的精准反馈、等待的安静悬念、收线的紧张博弈——三者交替构成完整的情绪弧线。
- **离线优先，尊重玩家时间**：不设体力条、不搞每日限制、不强制在线。玩家随时打开、随时钓、随时放下。
- **数据驱动，内容与逻辑分离**：鱼种、鱼饵、地图、装备数据由 CSV/JSON 外部配置驱动，方便迭代和社区贡献。

## 技术北极星

- **HTML5 Canvas + JavaScript + CSS**：选择纯前端栈而非游戏引擎，是为了保持代码轻量、零构建步骤、直接运行在浏览器中。Canvas 提供像素级控制，适合 2D 像素风格渲染。
- **外部 CSV 数据表驱动内容**：308 种鱼、35 种鱼饵、15 张地图等大量数据以 CSV 表格维护，游戏启动时加载。便于跨团队协作、差量更新和工具化编辑。
- **单例 Game Loop + ECS 启发式架构**：采用固定时间步长的主循环管理更新与渲染，实体（鱼、浮漂、UI 元素）以组件化方式组织，避免深继承树。
- **预留接口而非过度抽象**：账户、排行榜、烹饪、合成等系统的接口以桩（stub）形式预先定义，不引入复杂依赖框架，留出清晰扩展点。
- **零外部运行时依赖**：除浏览器外不需要任何运行时、框架或构建工具。`index.html` 可直接双击运行，也可通过任意静态服务器托管。

## 成功标准

- [ ] 三段式钓鱼循环完整可玩：抛竿精度小游戏 → 等待 → 刺鱼/收线音游判定，无逻辑断裂
- [ ] 至少 50+ 种鱼可被实际钓起，每种鱼有正确的稀有度和出现条件
- [ ] 4 类装备（竿/轮/线/钩）可装备、可更换，属性真实影响游戏行为
- [ ] 5+ 张地图可切换，地图切换影响鱼种分布
- [ ] XP 与等级系统工作，解锁逻辑生效
- [ ] 金币赚取与消费循环闭环（卖鱼 → 买装备/鱼饵 → 钓更好的鱼）
- [ ] 游戏可离线运行，双击 `index.html` 即可开始玩
- [ ] 代码仓库包含清晰的 README 和本 PROJECT.md

## 术语表

| 术语 | 说明 |
|------|------|
| **抛竿精度** | 抛竿阶段的小游戏：一个移动的指示条停在目标区域内，影响抛投距离与鱼种吸引力 |
| **收线判定** | 刺鱼/收线阶段的节奏判定：标记 `|` 向左移动，玩家需要在标记经过目标 `░` 时按键，判定分为 Perfect / Good / Miss |
| **完美判定（Perfect）** | 标记恰好落在目标区域内，显著提升收线成功率 |
| **装备属性** | 钓竿、渔轮、鱼线、鱼钩各自携带的 3–5 条数值属性（如抛投距离、收线速度、耐久度等） |
| **XP（经验值）** | 通过钓鱼获得，累积升级；经验曲线呈指数增长，等级越高每级所需 XP 越多 |
| **Gold（金币）** | 钓鱼收入和卖鱼获得的货币，用于购买装备、鱼饵和升级 |
| **鱼饵** | 消耗品，挂在不同鱼钩上影响特定鱼种的咬钩概率 |
| **地图** | 独立的水域场景，包含独特的鱼种组合、背景和水面视觉表现 |
| **图鉴** | 记录已发现/已钓取的鱼类信息，包含鱼种名称、描述、最大尺寸和稀有度 |
| **稀有度** | 鱼种分级（如普通/稀有/史诗/传说），影响出现概率、收线难度和售价 |
