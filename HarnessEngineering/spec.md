## 1. 游戏总览

### 1.1 游戏简介

《钓趣》是一款 2D 横版像素风钓鱼模拟游戏。玩家在不同水域地图中使用钓竿、鱼线、鱼钩和饵料，通过**抛竿精度小游戏**和**类音游收线判定系统**来钓取各种鱼类。鱼获可出售换金币、用于图鉴收集、放入水族箱展示，未来规划烹饪与装备制造系统。

### 1.2 核心循环

```
选择地图 → 准备钓具 → 抛竿(精度小游戏)
  → 等待咬钩(随机时间) → 咬钩提示
  → 收线搏鱼(音游判定) → 成功/失败结算
  → 获得经验值+金币 → 升级解锁内容 → 商店购买 → 继续钓鱼
```

### 1.3 核心数据文件

| 文件 | 内容 | 行数 |
|---|---|---|
| `table/FishTable.csv` | 305 种鱼的数据（属性、稀有度、体型、幂律参数等） | 306 |
| `table/BaitTable.csv` | 35 种饵料（类型、吸引力、耐久度等） | 36 |
| `table/MapDefinition.csv` | 15 张地图（难度、解锁等级、描述） | 16 |
| `table/MapFishSpawn.csv` | 809 条地图-鱼种刷新权重记录 | 810 |

## 2. 核心钓鱼机制（详细规格）

### 2.1 阶段一：抛竿（Casting）

#### 2.1.1 抛竿界面

抛竿时出现一个带刻度的**条状UI**，其核心架构为：

```
█ █ █ █ ░ █ █ █ █ █   ← 固定区域条
          |           ← 左右滑动的游标
```

- █：不可抛竿区域（填充色深灰）
- ░：可抛竿的**目标区**（填充色亮绿/闪烁）
- |：**游标**，从左到右循环移动，来回3次后抛竿失败（饵料/鱼线不消耗）
- 游标速度：匀速，1 次完整来回约 4s

> T-021 平衡：目标区缩窄至约 2.5% 后，游标速度同步降低（83→50%/s），保持 Perfect 判定窗口约 ±25ms

#### 2.1.2 目标区大小公式

```
目标区宽度 = BaseZoneWidth × (1 + 钓竿精度 × 0.3 + 鱼线灵敏度 × 0.2 + 鱼钩锋利度 × 0.2)
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `BaseZoneWidth` | 2.5% 条长 | 基础目标区大小（T-021 平衡：20%→2.5%，约 1/4） |
| 钓竿精度 | 0.0~1.0 | 高精度鱼竿缩小目标区但提供更好属性 |
| 鱼线灵敏度 | 0.0~1.0 | 灵敏度越高目标区越大 |
| 鱼钩锋利度 | 0.0~1.0 | 越高目标区越大 |

**交互与判定**：
- 按下抛竿键时，记录 `|` 相对于 `░` 的位置
- | 完全位于 ░ 内 → **Perfect Cast**（完美抛竿）
  - 后续钓到的鱼稀有度 +1 级（最多提升到上限+2）
  - 经验加成 ×1.2
- | 部分在 ░ 内（有50%以上重叠）→ **Good Cast**
  - 无加成
- | 在 ░ 外 → **Poor Cast**（抛歪）
  - 当前地图的常见鱼（Rarity 1-2）出现概率 ×1.5
  - 稀有鱼概率 ×0.8
- 3次来回未抛竿 → **Cast Fail**，不消耗饵料和鱼线

### 2.2 阶段二：等待咬钩（Waiting）

#### 2.2.1 等待逻辑

抛竿成功后进入等待状态，**等待时间** 由以下因素决定：

```
WaitTime(s) = BaseWait × FishRarityFactor × BaitAttractFactor × RandomRange(0.5, 1.5)
```

| 因子 | 说明 |
|---|---|
| `BaseWait` | 地图基础等待时间（见 MapDefinition，取值范围 5~30s） |
| `FishRarityFactor` | `1.5 - 0.5 × FishRarity`（常见鱼约1.0，稀有鱼约1.3） |
| `BaitAttractFactor` | `1.0 - 饵料吸引力/500`（吸引力越高等越快） |
| `RandomRange` | 均匀随机扰动，避免千篇一律 |

等待期间显示水面**浮漂动画**（像素风，有小鱼路过/水波/气泡等环境细节）。

#### 2.2.2 咬钩触发

- 鱼种选择：根据 `MapFishSpawn.csv` 中该地图的 `SpawnWeight` 加权随机
- 咬钩概率：`BaseBiteRate × (饵料吸引力/100) × 水层匹配修正`
  - `BaseBiteRate` = 0.5（基础咬钩率）
  - 水层不匹配修正 ×0.7，相邻水层 ×0.85，匹配 ×1.0 或 ×1.2
  - 鱼种 ActiveTime 与当前时间不匹配 ×0.6
- 咬钩时产生**视觉+音效提示**（浮漂下沉、水花特效、屏幕闪烁）

### 2.3 阶段三：收线搏鱼（Rhythm Catch）

#### 2.3.1 界面布局

咬钩后进入**双耐力条搏鱼界面**，页面分为三个区域：

```
┌──────────────────────────────────────┐
│  鱼耐力条: ████████░░ 78%            │ ← 鱼图标 + 耐力条
├──────────────────────────────────────┤
│                                      │
│   █ █ ░ █ █ █ | █ █ | █ █ █       │ ← 类音游判定条（横向滚动）
│      ↑ 判定目标区                     │
│                                      │
├──────────────────────────────────────┤
│  玩家耐力条: ████████░░ 80%          │ ← 玩家图标 + 耐力条
└──────────────────────────────────────┘
```

- **上方**：鱼耐力条（红色），显示鱼剩余体力，附带鱼图标（随耐力降低呈现疲劳动画）
- **中部**：类音游判定条，判定标记（note）从右向左移动
- **下方**：玩家耐力条（蓝色），显示玩家剩余体力

#### 2.3.2 耐力值计算

**鱼耐力值**（初始值 = 最大耐力）：

```
鱼最大耐力 = FightPower × 60 + Rarity × 150 + 100（T-021 平衡三轮：四星鱼血量过千）
```

| 挣扎强度 | 鱼耐力值 | 举例 |
|---|---|---|
| 1-2 | 310~520 | 鲫鱼、白条（易） |
| 4-6 | 700~1210 | 鲤鱼、青鱼（中） |
| 7-9 | 1540~1840 | 金枪鱼、鲨鱼（难） |
| 10 | 2200 | 传说级 |

> T-021 平衡二轮：由 `×14+×8+24` 上调为 `×20+×12+36`（拉长战斗时间）

**玩家耐力值**（初始值 = 最大耐力）：

```
玩家最大耐力 = 钓竿强度 × 1.5 + 渔轮刹车力 × 4.0 + 鱼线拉力 × 0.6 + 50
```

- 装备越好，玩家耐力越高
- 初始基础装备约 235 耐力，顶级装备约 350 耐力

> T-021 平衡二轮：由 `×1.5+×5+×0.8+50` 下调（玩家更脆弱，miss 代价更重）

#### 2.3.3 判定标记（Note）生成

```
判定标记数 = 4 + Floor(挣扎强度 × 1.5) + Floor(稀有度 × 0.5)
```

| 挣扎强度 | 标记数 | 举例 |
|---|---|---|
| 1-2 | 5-8 | 鲫鱼、白条 |
| 4-6 | 10-14 | 鲤鱼、鲶鱼 |
| 7-9 | 15-21 | 金枪鱼、大白鲨 |
| 10 | 24 | 传说级 |

> T-021 平衡调整：由 `×1.2+×0.4` 上调为 `×1.5+×0.5`（难度曲线更陡）

**节奏控制**：
- 标记间隔时间 = `700ms - 挣扎强度 × 50ms`（挣扎越高越快）
- 每个标记到达目标区的时间约 2~3 秒（逻辑）
- 键的视觉移动约 1.7 秒（2026-07-27 用户反馈：1.5→1.7 秒，下落速度稍慢约 13%）
- 给玩家 1.7 秒准备时间，第一个标记从轨道起点开始移动
- 当鱼耐力 < 25% 时进入**狂暴阶段**：标记间隔缩短 25%，速度增加 20%

> T-021 平衡二轮：间隔由 `760-×40` 收紧为 `700-×50`（节奏更密）

> 键表生成（2026-07-27 用户反馈）：键表按"整场战斗所需命中次数"一次性预生成
> （约 = 鱼耐力 / (基础伤害 × 0.75) × 1.3，且 ≥ 公式基础数量），战斗中途不再补充
> "从屏幕中间突然冒出"的键；补充机制仅作键表耗尽的兜底，且新键从轨道起点进入。
>
> **Boss 复杂键型**（参考 1K 音游如太鼓达人的时间结构，Boss 战轮换使用、不连续重复）：
> - `xx xx xx` — 三组二连弹（组内 150ms / 组间 320ms）
> - `xxxx` / `xxxxxx` — 四连 / 六连纵连（150ms 均匀连打）
> - `xxxxxx xxxxxx` — 两组六连（组间 400ms）
> - `xxxxxx|-----` / `xx x xx x xxxxxx|-----` — 连打接长按的组合复杂键型
> - `stair` — 变速楼梯（间隔交替 150~300ms）
> 普通鱼保持 tap / double / triplet / hold / accel 混合生成。
>
> 2026-07-27 用户反馈"轻松模式活不过三秒"：① 修复 Boss 键型**时间重叠 bug**
> （节拍间隔此前未累积，多个键落在同一时刻 → 打中一个其余自动 Miss）；
> ② 连打间隔 110~115ms → 150ms、组间隔放宽（更易击打）；
> ③ 轻松模式 miss 扣血 12%→10%、perfect 回血 4%→5%。

#### 2.3.4 判定精度与伤害

当标记移动到 `░` 目标区时，玩家按下判定键：

| 评级 | 偏移窗口 | 概率系数 p | 玩家耐力损失 |
|---|---|---|---|
| Perfect | ±25ms | 1.0 | 0（不掉耐） |
| Great | ±50ms | 0.75 | 玩家最大耐力 × 2% |
| Good | ±80ms | 0.50 | 玩家最大耐力 × 5% |
| Miss | >80ms | 0.0 | 玩家最大耐力 × 12% |

> T-021 平衡二轮：Great/Good 窗口由 ±60/±100 收窄为 ±50/±80（更高精度要求）

**伤害公式**（每次判定对鱼耐力造成伤害）：

```
对鱼伤害 = 基础伤害 × p

基础伤害 = 钓竿强度/8 + 鱼钩锋利度/4 + 渔轮速比 × 2.5 + 鱼线拉力/6
```

- 装备越好，每次 Perfect 伤害越高
- p = 0 时（Miss）不对鱼造成伤害

**示例**（中等装备：钓竿强度=40，鱼钩锋利度=30，渔轮速比=4.0，鱼线拉力=20）：
- 基础伤害 = 40/8 + 30/4 + 4.0×2.5 + 20/6 ≈ 5 + 7.5 + 10 + 3.33 = **25.83**
- Perfect 伤害 = 25.83 × 1.0 = **25.83**
- Great 伤害 = 25.83 × 0.75 = **19.4**
- Good 伤害 = 25.83 × 0.5 = **12.9**
- Miss 伤害 = 0

#### 2.3.5 判定标记移动速度

```
基础速度(px/s) = 84 + FightPower × 8
```

- 稀有度 > 7 的鱼：速度 +15%
- 变异鱼：速度 +20%
- 鱼耐力 < 25%（狂暴阶段）：速度 +20%
- 体型越大速度越快（`该鱼长度/物种最大长度` 影响）

> T-021 平衡调整：由 `80+×6` 上调为 `84+×8`（整体更快）

#### 2.3.6 胜负判定

对拼持续到其中一方耐力条归零：

```
胜利条件：
  - 鱼耐力 ≤ 0 → 🏆 成功钓获！进入结算界面
  - 玩家耐力 ≤ 0 → 💔 逃脱失败！鱼逃跑，消耗1鱼线+1饵料
```

**断线保底机制**：若单次 Miss 时计算出的玩家耐力损失超过剩余耐力，仍以耐力归零处理，但附加"断线"特殊动画（线崩断的特效）。

**狂暴阶段**：鱼耐力 < 25% 时（视若归零前的爆发），标记速度+20%、间隔缩短25%，玩家需集中注意力完成最后冲刺。

**连击奖励**（可选增强）：
- 连续 Perfect ≥ 3 次 → 下一次 Perfect 伤害 × 1.5（暴击），屏幕闪白光
- 连续 Perfect ≥ 5 次 → 下一次 Perfect 伤害 × 2.0，附带"哎哟！"鱼表情动画

#### 2.3.7 判定反馈（Feedback）

每次判定触发以下反馈以增强操作感：

| 反馈 | 实现方式 |
|---|---|
| **Note 放大+虚化** | 判定瞬间标记放大至 150% 并添加 motion blur 虚化，150ms 内恢复 |
| **音效** | Perfect→清脆"叮"；Great→中音"咚"；Good→沉闷"砰"；Miss→"嘶"漏气声 |
| **屏幕抖动** | Perfect 微抖 2px，Good 中抖 5px，Miss 大抖 8px（持续 100ms） |
| **耐力条闪烁** | 当任意方耐力 < 20% 时耐力条闪烁红色警告 |
| **鱼表情** | 鱼图标随耐力降低逐步变化：平静 → 皱眉 → 翻白眼 → 翻肚皮（最后阶段） |

#### 2.3.8 消耗规则

- 每次钓鱼（无论成功/失败）均消耗 **1 鱼线 + 1 饵料**
- 仅当成功抛竿且鱼咬钩后才进入收线阶段，消耗才生效
- 断线时鱼线消失，鱼钩返回（不消耗鱼钩）

### 2.4 阶段四：结算（Result Screen）

成功钓上鱼后展示结算界面，包含：

| 🎨 像素鱼图 | 随机生成的像素风格鱼图 |

| 🏆 新纪录标记 | 若打破个人纪录则高亮标注 |

## 3. 装备系统（Equipment）

### 3.1 装备槽位

玩家拥有 4 个装备槽位：

| 槽位 | 属性 | 影响维度 |
|---|---|---|
| **钓竿 (Rod)** | 强度、精度、韧性、长度、弹性 | 抛竿精度、搏鱼成功率 |
| **渔轮 (Reel)** | 速比、刹车力、容线量、耐用度 | 收线速度、防止断线 |
| **鱼线 (Line)** | 拉力、灵敏度、隐蔽性、耐磨度 | 防断线、目标区大小 |
| **鱼钩 (Hook)** | 锋利度、强度、大小、倒刺 | 刺鱼成功率、目标区大小 |

> 注：原始需求为"鱼竿、鱼线、鱼钩"三类。此处增加"渔轮"作为第四类，让系统更有深度和策略性。如果需简化至三类，可将渔轮属性合并入钓竿。

### 3.2 属性详解

#### 3.2.1 钓竿 (Rod)

| 属性 | 范围 | 效果 |
|---|---|---|
| `strength` (强度) | 1~100 | 搏鱼时减少脱钩概率 |
| `precision` (精度) | 1~100 | 影响抛竿目标区宽度 |
| `toughness` (韧性) | 1~100 | 减少鱼线断裂概率、抗大拉力 |  
| `length` (长度) | 1~10 | 增加抛竿最大距离 |
| `elasticity` (弹性) | 1~100 | 缓冲鱼的冲刺力量，减少体力消耗 |

#### 3.2.2 渔轮 (Reel)

| 属性 | 范围 | 效果 |
|---|---|---|
| `gearRatio` (速比) | 3.0~8.0 | 收线速度倍率 |
| `dragPower` (刹车力) | 1~30 | 抵抗大鱼冲刺，防止断线 |
| `lineCapacity` (容线量) | 50~500 | 可使用的鱼线最大磅数限制 |
| `durability` (耐用度) | 1~100 | 渔轮耐久，越高越耐用 |

#### 3.2.3 鱼线 (Line)

| 属性 | 范围 | 效果 |
|---|---|---|
| `tensile` (拉力) | 1~100 | 承受挣扎力上限，拉力低于挣扎力时断线 |
| `sensitivity` (灵敏度) | 1~100 | 影响抛竿目标区宽度 |
| `stealth` (隐蔽性) | 1~100 | 降低高稀有度鱼的警惕性，减少警觉 |
| `abrasion` (耐磨度) | 1~100 | 避免被岩石/障碍磨损断线 |

#### 3.2.4 鱼钩 (Hook)

| 属性 | 范围 | 效果 |
|---|---|---|
| `sharpness` (锋利度) | 1~100 | 影响抛竿目标区宽度 |
| `strength` (强度) | 1~100 | 防止钩被拉直/断裂 |
| `size` (大小) | 1~10 | 影响可钓的鱼种大小匹配 |
| `barb` (倒刺) | 0/1 | 有倒刺减少脱钩率，但降低出钩速度 |

### 3.3 装备稀有度与品质

每件装备有 5 个品质等级，影响总属性值：

| 品质 | 颜色 | 属性倍率 |
|---|---|---|
| 普通 (Common) | 白 | ×1.0 |
| 优秀 (Uncommon) | 绿 | ×1.2 |
| 稀有 (Rare) | 蓝 | ×1.5 |
| 史诗 (Epic) | 紫 | ×1.8 |
| 传说 (Legendary) | 橙 | ×2.2 |

### 3.4 商店与价格

- 商店按等级解锁（Lv.1 开放基础装备，每 5 级刷新更高级装备）
- 装备价格公式：`BasePrice × QualiltyMultiplier × TypeMultiplier`
- 每日/每 10 次钓鱼后商店刷新一次随机商品

## 4. 经济系统

### 4.1 经验值与等级

#### 4.1.1 升级经验公式

```
第N级所需经验 = Floor(100 × 1.15^(N-1))
```

即指数型增长曲线，基础100，每级增加15%：

| 等级 | 所需经验 | 累计 |
|---|---|---|
| 1→2 | 100 | 100 |
| 2→3 | 115 | 215 |
| 5→6 | 175 | 672 |
| 10→11 | 350 | 2,030 |
| 20→21 | 1,417 | 10,286 |
| 50→51 | 71,358 | 543,692 |

#### 4.1.2 等级解锁

| 等级 | 解锁内容 |
|---|---|
| Lv.1 | 乡村池塘、城市运河（基础钓竿+基础线） |

### 4.2 金币经济

- **收入**：出售鱼获（按基础价×个体加成）
- **支出**：购买饵料、钓竿、鱼线、鱼钩、渔轮
- **经济平衡**：低等级地图钓常见鱼 → 收支平衡略有盈余
  - 高等级地图需要好的装备投入 → 高风险高回报

### 4.3 鱼获商业价值公式

```
实际售价 = BasePrice_Gold × (1 + SizeBonus + MutationBonus + QualityBonus)
```

各因子定义见 `plan.md`（数据设计文档）第三章 3.3 节。

## 5. 地图系统

### 5.1 地图解锁

- 15 张地图通过玩家等级解锁（见 4.1.2）
- 每张地图包含独特的**景观像素背景**、**专属BGM**、**特定鱼种组合**
- 地图切换时播放加载动画

### 5.2 地图鱼种权重

每张地图中每种鱼的出现概率完全由 `MapFishSpawn.csv` 的 `SpawnWeight` 决定：

```
P(鱼A) = SpawnWeight_A / Σ(该地图所有SpawnWeight)
```

SpawnWeight 的生成算法见 `plan.md` 第六章 6.3 节。

### 5.3 地图环境参数

每张地图运行时携带以下环境参数（影响钓鱼体验）：

| 参数 | 来源 | 影响 |
|---|---|---|
| `baseWaitTime` | MapDefinition | 等待咬钩的基础时间 |
| `weatherProb` | 地图固定 | 天气概率分布（晴朗/多云/雨/风暴） |
| `waterClarity` | 地图固定 | 影响抛竿目标区可见度（0.3~1.0） |
| `tideEffect` | 河口/海水图 | 潮汐影响鱼种活跃度 |

## 11. 钓场加成与饵料差异（T-021 平衡）

### 11.1 高级钓场加成（需求3）

高级钓场（难度更高）提供更高的鱼数值与稀有度加成：

| 加成项 | 公式 | 说明 |
|---|---|---|
| 鱼血量加成 | 血量 = 基础血量 × (1 + (难度-1) × 0.12) | 难度 10 钓场鱼血量 ×2.08 |
| 体型加成 | 体长 × (1 + (难度-1) × 0.04) | 难度 10 钓场鱼体型 +36% |
| 稀有度加成 | 选鱼时 Rarity≥5 的鱼权重 × (1 + (难度-1) × 0.15) | 难度 10 钓场稀有鱼出现率 ×2.35 |

### 11.2 饵料可感知差异（需求4）

| 效果 | 机制 | 说明 |
|---|---|---|
| 吸引力 | Attractiveness → 咬钩率与等待时间 | 原有 |
| 类别匹配 | 饵料 TargetCategory 与鱼类别相同 → 该鱼选鱼权重 ×1.5 | 用对饵料更容易钓到目标类别 |
| 体型加成 | 体型加成 = (饵料 Rarity - 1) × 6% | Rarity5 饵料钓到体型 +24% 的大鱼，售价/经验更高 |
| UI 展示 | 钓鱼界面与商店显示吸引力/体型加成 | 直观可见 |

## 12. Boss 挑战模式（需求2）

- **入口**：地图选择页右上"⚔ BOSS"。
- **规则**：直接进入搏鱼战斗（跳过抛竿/等待），Boss 血量极高（7500~12000）、体型较大（130~260cm）、键型密集（间隔 ×0.75~0.85）且复杂。
- **特性（常驻）**：对玩家耐力伤害提高（×1.2~1.5）或玩家耐力上限降低（×0.9）。
  （2026-07-27 用户反馈：过高下调——×1.5/×2.0 → ×1.2/×1.5，×0.8 → ×0.9）
- **技能（周期）**：每（激活+冷却）循环开启一次，如"3 秒免疫 Good 伤害，冷却 10 秒"；技能类型：immuneGood / immuneGreat / immunePerfectOnly。
- **奖励**：击败后获得金币奖励（2500~5000），并标记"已击败！"（持久化，可重复挑战）。
- **Boss 列表**（全部信息见游戏内介绍）：深渊巨鳗 / 熔岩鲶 / 极光龙鲤。
