### T-010: 鱼生成算法
- **状态**: pending
- **前置依赖**: T-002, T-008
- **模块**: Gameplay/FishGenerator
- **步骤**:
  1. 根据选定的鱼种（来自 T-008）生成具体个体：体长服从 Gamma 分布（shape=2, scale=基准长/2）
  2. 体重按幂律计算：`weight = a * length^b`（a/b 由鱼种决定）
  3. 稀有颜色突变：~5% 概率出现特殊色（金色/彩虹/暗影），属性微调
  4. 品质判定：根据长度百分比决定 Common / Uncommon / Rare / Legendary
  5. 返回 `FishInstance` 对象：包含 species、length、weight、quality、mutation、捕获时间等
- **验收标准**:
  - [ ] 同种鱼连续生成 50 次，体长分布呈现右偏 Gamma 形态
  - [ ] 金色/彩虹突变出现概率约 5%，可重复验证
  - [ ] 品质判定逻辑正确，传奇品质仅出现在 ~98% 分位数以上
  - [ ] FishInstance 数据结构完整，可直接存入存档
- **预估时间**: 3h
